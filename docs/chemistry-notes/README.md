# O-Level Chemistry Formula Sheet

This project contains a printable one-page-style HTML revision sheet for O-Level chemistry.

## Open locally

Open [`index.html`](./index.html) in a browser.

## What is included

- Core quantitative chemistry formulas
- States of matter, diffusion, and separation techniques
- Atomic structure, bonding, and periodic trends
- Moles, stoichiometry, titrations, and gas calculations
- Acids, bases, salts, redox, electrolysis, and reactivity
- Organic chemistry, industrial chemistry, air and water topics
- Qualitative analysis tests and solubility rules

## Notes

The sheet is written as a broad O-Level revision aid. Exact syllabus emphasis can vary slightly by exam board and option route.
